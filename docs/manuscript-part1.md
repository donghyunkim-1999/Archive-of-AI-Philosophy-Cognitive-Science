# A. 전역 변경

## A-1. 색 토큰 교체 (모든 파일)

6개 파일이 각자 `:root`를 갖고 있습니다. 전부 아래로 교체합니다.
(`archive.css`로 추출하면 이후로는 한 곳만 고치면 됩니다.)

```css
:root{
  --paper:#f5f2ec;        /* 바탕. 따뜻한 종이 */
  --ink:#1c1f24;          /* 제목·강조 */
  --body:#4c525c;         /* 본문 */
  --machine:#3a5370;      /* 의심1 · 기호와 규칙 (차가운 청) */
  --mind:#9a4f2c;         /* 의심2 · 마음과 중심 (테라코타) */
  --fog:#8b9099;          /* 보조 */
  --line:rgba(28,31,36,.14);
  --line-soft:rgba(28,31,36,.08);
}
```

⚠ **단순 치환 금지.** 기존 코드는 `--ink`가 **배경**이고 `--mind`가 **본문 글자**였습니다. 새 토큰에서는 `--paper`가 배경, `--ink`가 제목입니다. 역할이 뒤바뀝니다.

```
background:var(--ink)      →  background:var(--paper)
color:var(--mind)  (본문)   →  color:var(--body)
color:var(--mind)  (제목)   →  color:var(--ink)
```

**두 색의 대비는 유지합니다.** `--machine`(청)과 `--mind`(테라코타)가 의심1/의심2를 가르는 것은 장식이 아니라 논지의 시각화입니다.
