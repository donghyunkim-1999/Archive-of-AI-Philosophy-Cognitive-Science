## 2. 공통 파일 추출 — 가장 중요한 단계

> `00-orientation.html`이 새 라이트 테마의 기준 파일이야. 이 파일에서 공통 부분을 뽑아 `archive.css`와 `archive.js`를 만들어줘.
>
> **`archive.css`에 들어갈 것**
> `:root` 토큰 · body · nav · rail · section · 공통 타이포(h1 h2 eyebrow body-t pull hinge names) · `.tri` `.pos` · `.room` 계열 · `.related` `.xcard` · `.chnav` · `.reveal` · 오버레이 · 미디어쿼리
>
> **`archive.js`에 들어갈 것**
> 캔버스 파티클 엔진 · 해시 라우팅(showView / goRoom / goChapter / route) · IntersectionObserver 두 개(모드 전환·리빌) · 진행바와 레일
>
> **⚠ 페이지마다 다른 것은 각 파일에 남기고 매개변수로 넘겨줘.**
> - 캔버스 **모드 정의가 파일마다 전부 다름**:
>   `00` ambient·stance·lattice-break·decenter·converge
>   `01` lattice·latticecrack·network·drift·converge
>   `02` tri·lattice·hier·scatter·converge
>   `03` orbit·boundary·network·dissolve
>   `04` scatter·gravity·orbit2·converge
>   `index` 모드 없음(단순 연결선 그물)
>   → 엔진은 공통, **모드별 좌표 계산은 페이지가 주입**하는 형태로
> - 해시 라우팅은 `01`~`04`에만 있음. `index`·`00`에는 없음
> - `rooms` 배열, `roomTitles`, `crumbBase`는 페이지마다 다름
>
> 그다음 `index.html`과 `01`~`04`에서 중복된 CSS·JS를 걷어내고 두 파일을 참조하게 바꿔줘.
>
> **⚠ 색 토큰은 단순 치환하면 안 돼.**
> 기존 파일은 `--ink`가 **배경**이고 `--mind`가 **본문 글자**야. 새 토큰은 `--paper`가 배경, `--ink`가 **제목**이라 역할이 뒤바뀌어.
> `background:var(--ink)` → `background:var(--paper)`
> 본문의 `color:var(--mind)` → `color:var(--body)`
> 제목의 `color:var(--mind)` → `color:var(--ink)`
> 하나씩 판단해서 바꿔줘.

**한 파일씩 시키세요.** 여섯 개를 한 번에 맡기면 검증이 안 됩니다.

> 먼저 `01-rules-to-patterns.html` 하나만 해줘. 잘 되면 나머지에 같은 방식으로 적용하자.

**확인**: 브라우저로 `01`을 열어서 파티클이 움직이는지, 방 카드 클릭이 되는지, 색이 안 깨졌는지.

## 5. 검사

> 전체 파일에서 아래를 찾아줘. 고치지 말고 목록만 보여줘.
>
> 1. `font-weight:300`이 남아 있는 곳
> 2. `var(--ink)`를 배경으로 쓰는 곳
> 3. 옛 캔버스 색 — `rgba(255,255,255`, `rgba(217,205,184`, `rgba(126,142,163`
> 4. `--mind`·`--machine` 외에 옛 토큰(`--fog-2`, `--ink-2`, `--paper-dim`)이 남아 있는 곳
> 5. **'세미나' · '전사본' · '판서' · 'N강'이 들어간 문장**
> 6. `의미는 고정되어 있는가` (DOUBT 01 옛 이름)
> 7. `데리다` 또는 `différance`

5~7번이 금칙어·개명 검사입니다. 하나라도 걸리면 원고에서 놓친 겁니다.

## Claude Code가 하려고 하면 막을 것

- **파일을 통째로 새로 쓰려고 할 때** → "기존 파일을 수정해줘, 새로 쓰지 말고"
- **여러 파일을 한 번에 고치려고 할 때** → "한 파일씩 하자"
- **`id`나 `data-room` 값을 바꾸려고 할 때** → 링크가 전부 깨집니다. 절대 금지
- **`.related` 카드의 내용을 고치려고 할 때** → 원고에 없는 건 손대지 않습니다
- **원고에 없는 문구를 '개선'하려고 할 때** → "원고에 있는 것만 적용해줘"
